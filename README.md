# 🦷 Consultorio Dental — Backend

API REST para la gestión de un consultorio dental. Permite administrar pacientes, agendar citas y llevar el historial clínico, con autenticación segura mediante JWT.

---

## 🚀 Tecnologías

- **Node.js** + **Express** — servidor y enrutamiento
- **MySQL** — base de datos relacional
- **Mongoose** — modelado de datos
- **JWT** — autenticación y autorización de usuarios

---

## ✨ Funcionalidades

- 👤 **Gestión de pacientes** — registro, consulta, actualización y eliminación
- 📅 **Citas y agenda** — programación y control de citas
- 📋 **Historial clínico** — registro del historial médico por paciente
- 🔐 **Autenticación** — login seguro con tokens JWT

## ⚙️ Instalación y uso

```bash
# Clona el repositorio
git clone https://github.com/AlanCovarrubias999/CD-Backend.git

# Entra al directorio
cd CD-Backend

# Instala las dependencias
npm install

# Configura las variables de entorno
cp .env.example .env
# Edita el archivo .env con tus credenciales

# Inicia el servidor
npm run dev
```
